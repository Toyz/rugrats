# Worklog

Running engineering log for reverse engineering Rugrats: Search for Reptar
(PlayStation, SLUS-00650) and porting it to the PC. One file per entry under
[`worklog/`](worklog/), newest at the bottom. This index is generated by
`cairns index` - edit the entries, not this file.

Code says what; the worklog says *how we found out* and *why it is that way*.
The [reference](docs/README.md) says what is true now.

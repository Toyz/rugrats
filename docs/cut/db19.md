# Database 19

`/DATA/DB19` ships with seven files, and the game's
[file table](../formats/file-table.md) has no entry for any of them: every
per-database group (MOD 261, ANM 293, FRM 325, ROT 357, HIE 389, LP 421,
LEVEL 453, COL 485, A.RAW 518, TEXPOS 572) holds 0 in the DB19 slot.

| file | lba | bytes |
| --- | ---: | ---: |
| `DB19A.RAW` | 123455 | 294912 |
| `DB19ANM.BIN` | 123599 | 5120 |
| `DB19LP.BIN` | 123602 | 27748 |
| `LEVEL19.BIN` | 123616 | 348584 |
| `LEVEL19.COL` | 123787 | 46364 |
| `Q.DAT` | 123810 | 3752 |
| `TEXPOS.DAT` | 123812 | 5136 |

Missing against a complete database: `DB19MOD.BIN`, `DB19FRM.BIN`,
`DB19ROT.BIN`, `DB19HIE.BIN` and `SPEECHTB.DAT`, and its `.ISF` music and
`DB19SFX` bank. `Q.DAT` is in no other database.

The executable's database names, from 0x800bb744 in order, put
"No More Cookies" twentieth (index 19 if the list starts at DB00); a debug
string reads "should trigger LVL_NO_MORE_COOKIES next". That mapping is not yet
checked against the code that indexes the list.
